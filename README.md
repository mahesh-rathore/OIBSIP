# Online Reservation System

A Java-based Online Reservation System developed as part of my Java Development Internship at Oasis Infobyte (OIBSIP).

## Features

- User Login System
- Book Train Tickets
- Automatic Train Name Fetching
- Unique PNR Generation
- Search Reservation Details
- Ticket Cancellation
- Input Validation
- MySQL Database Integration
- User-Friendly Java Swing Interface

## Technologies Used

- Java
- Java Swing
- JDBC
- MySQL
- Maven
- IntelliJ IDEA
- Git & GitHub
