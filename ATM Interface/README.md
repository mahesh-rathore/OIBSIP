# ATM Interface

## Oasis Infobyte - Java Development Internship

### Task
Task 3 - ATM Interface

## Objective

A console-based ATM simulation developed using Java and Object-Oriented Programming concepts.

The application allows users to authenticate using User ID and PIN and perform basic banking transactions.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
- IntelliJ IDEA

## Features

- User ID and PIN authentication
- Maximum 3 login attempts
- Transaction History
- Withdraw money
- Deposit money
- Transfer money
- Insufficient Funds validation
- Recipient account validation
- Quit option

## Project Structure

- `Main.java` - Starts the ATM application
- `ATM.java` - Handles login, menu and banking operations
- `Account.java` - Stores account information
- `Transaction.java` - Represents transaction details
- `Bank.java` - Manages accounts

## How to Run

1. Open the project in IntelliJ IDEA.
2. Make sure JDK is configured.
3. Open `Main.java`.
4. Run `Main.java`.
5. Enter a valid User ID and PIN.
6. Select an option from the ATM menu.
